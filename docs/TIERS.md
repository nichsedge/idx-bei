# Support / Punish Tiers (0-100 scores, normalized)
- 90-100: Strong Support (high benefit/low toxicity, verified sources)
- 70-89: Lean Support
- 50-69: Neutral / Monitor
- 30-49: Lean Punish (elevated toxicity / low benefit)
- 0-29: Strong Punish (toxic ormas / corrupt board links, low confidence flagged)
Every tier tied to `confidence` tag (`high`/`medium`/`low`) and `source_url`.
